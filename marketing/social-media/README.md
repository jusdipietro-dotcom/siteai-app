# Automatic IA Lab - Instagram Campaign Assets

## Overview

This directory contains the professional Instagram marketing campaign for **Automatic IA Lab**, an AI-powered website builder for local businesses in Argentina. The campaign follows the "Circuit Clarity" design philosophy—a visual movement that blends circuit board precision with modern SaaS accessibility.

## Design System

### Brand Colors
- **Dark Navy**: #0f172a (primary background)
- **Cyan**: #06b6d4 (accent and glow elements)
- **White**: #ffffff (primary text)
- **Light Gray**: #94a3b8 (secondary text and subtle accents)

### Typography
- **Headlines**: BigShoulders-Bold (powerful, tech-forward)
- **Body Text**: BricolageGrotesque-Regular (clean, accessible)
- **Monospace**: GeistMono-Bold (technical precision)

### Design Principles - "Circuit Clarity"

The visual philosophy emphasizes:
1. **Precision**: Geometric patterns, circuit nodes, and connection elements
2. **Clarity**: Clean typography and generous spacing
3. **Warmth**: Glowing cyan accents that feel energetic, not cold
4. **Accessibility**: Modern SaaS design that speaks to all users
5. **Mastery**: Meticulously crafted details showing engineering excellence

See `design-philosophy.md` for the complete philosophy document.
